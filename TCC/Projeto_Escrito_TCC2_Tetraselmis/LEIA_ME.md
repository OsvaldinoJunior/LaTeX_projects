# Trabalho escrito — TCC 2: Tetraselmis chuii

Versão compilada em 3 de novembro de 2026.

- `Trabalho_TCC2_atualizado.pdf`: versão atual para leitura.
- `main.tex`, `conteudo/`, `config/` e `zotero.bib`: fontes editáveis do trabalho.
- `image/`: figuras incluídas no documento.
- `graficos_lollipop/` e `graficos_lollipop_interacoes/`: gráficos e dados de apoio.
- `compilar.sh`: compilação local com pdfLaTeX. O cache bibliográfico incluído permite compilar sem Biber enquanto `zotero.bib` não for alterado.

Para editar, abra `main.tex`. Para recompilar, execute `bash compilar.sh` nesta pasta.
